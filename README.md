# infraPPE-monitor

![Icon](./docs/infraPPE-icon.jpg)
**infraPPE-monitor** - это интеллектуальный модуль промышленной безопасности, анализирующий **инфракрасные (ИК) изображения** для контроля соблюдения правил использования средств индивидуальной защиты (СИЗ) в условиях __низкой видимости__ — при дыме, тумане, пыли или полном отсутствии света.


## 🎯 Цель проекта
Создать систему, способную:
* работать с ИК-видеопотоком в реальном времени (до 25 кадров/с);
* распознавать тип и корректность ношения СИЗ (каска, респиратор, очки, перчатки);
* оценивать уровень риска и выдавать объяснение причины нарушения;
* интегрироваться в существующие системы безопасности (MES / ERP / доступ);
* самообучаться на метках оператора для снижения ложных срабатываний.


## ⚙️ Технологии
- __Python__, OpenCV, NumPy,
- __Обработка видео__: cv2.VideoCapture,
- __ИК-симуляция__: синтетические тепловые карты (можно генерировать из RGB через преобразование),
- __ML__: детекция и классификация СИЗ через YOLOv8,
- __Интерфейс__: Streamlit для демонстрации результатов.
